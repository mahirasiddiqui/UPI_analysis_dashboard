# UPI Transaction Analysis Dashboard | Microsoft Excel

## Project Overview

An interactive UPI Transaction Analysis Dashboard developed using Microsoft Excel to explore digital payment transaction patterns, analyze transaction performance, and visualize key business metrics.

The dashboard provides an overview of transaction volumes, payment amounts, cashback, success rates, suspected fraud, and usage patterns across different dimensions.

**Project Type:** Guided Learning Project  
**Tool:** Microsoft Excel  
**Domain:** FinTech | Business Analytics | Data Analysis

## Key Performance Indicators (KPIs)

The dashboard highlights five key metrics:

- Total Transactions
- Total Transaction Amount (INR)
- Total Cashback (INR)
- Transaction Success Rate
- Suspected Fraud Transactions

## Key Features & Analysis

### 1. Interactive Filters
- City
- Gender
- Merchant Category
- Merchant Name

### 2. Transaction Trend Analysis
- Daily transaction amount trends
- Hourly transaction patterns
- Day-wise and hour-wise transaction heatmap

### 3. Payment Analysis
- Transaction distribution across UPI applications
- Transaction status analysis
- Transaction amount by bank
- Transaction amount by payment type

### 4. Geographical Analysis
- State-wise transaction amount distribution across India
